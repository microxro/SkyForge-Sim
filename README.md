# Review frames (generated)

Rewritten by .github/workflows/frames.yml (job publish-frames) on each push to main.

- main/: frames from the latest push to main. commit.txt names the commit.
- pr-<number>/: frames for open pull requests, published by .github/workflows/pr-frames.yml.

Raw link pattern: https://raw.githubusercontent.com/<owner>/<repo>/ci-frames/main/<name>.png
